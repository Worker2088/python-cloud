4. Как распределить слои в src/storage/ с учетом MinIO (S3)
В облачном хранилище у фичи всегда два источника данных:
Реляционная БД (для быстрой навигации по дереву, поиска, хранения прав) и
Object Storage MinIO (для хранения самих байтов). Архитектура должна это красиво разруливать.

models.py (Метаданные в SQL)
Здесь лежит модель SQLAlchemy. В S3 нельзя быстро сделать древовидный поиск
или эффективно связать файлы связью «многие к одному» с пользователем. Поэтому в БД мы храним структуру:

Python
class StorageObject(Base):
    __tablename__ = "storage_objects"

    id = Column(UUID, primary_key=True)
    user_id = Column(ForeignKey("users.id"), nullable=False)
    name = Column(String, nullable=False)
    path = Column(String, nullable=False)  # Например: "documents/resume.pdf"
    type = Column(String, nullable=False)  # "FILE" или "DIRECTORY"
    size = Column(Integer, nullable=True)
    s3_key = Column(String, nullable=True) # Уникальное имя бакета/объекта в MinIO

client.py (Объектное хранилище MinIO)
Класс, завернутый в синглтон или зависимость, который инициализирует boto3.client("s3", ...)
и предоставляет чистые методы: upload_file_blob(), download_file_blob(), delete_file_blob().
Он ничего не знает про SQLAlchemy и пользователей.

repository.py (Репозиторий метаданных)
Обычный репозиторий для работы с SQLAlchemy-моделью StorageObject. Умеет делать get_by_path(),
create_object(), delete_object().

service.py (Бизнес-логика / Сервис)
Это главный "дирижер" (Use Case слой). Именно сюда через конструктор (__init__)
залетают StorageRepository и MinioClient.

Когда пользователь загружает файл, Service делает две вещи в рамках одной бизнес-операции:

Генерирует уникальный s3_key, отправляет файл в MinioClient.upload_file_blob().

Если загрузка успешна, берет метаданные и вызывает StorageRepository.create_object(),
чтобы зафиксировать файл в базе данных.

dependencies.py (Внедрение зависимостей)
Здесь ты собираешь этот пирог для FastAPI:

Python
async def get_storage_repository(session=Depends(get_db_session)):
    return StorageRepository(session)

async def get_storage_service(
    repo=Depends(get_storage_repository),
    s3_client=Depends(get_s3_client)
):
    return StorageService(repo, s3_client)
